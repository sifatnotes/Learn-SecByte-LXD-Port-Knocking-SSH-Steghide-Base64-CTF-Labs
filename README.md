## Learning Path

A practical progression through this collection is:

1. Begin with **Knock Enumerate** to establish reconnaissance fundamentals.
2. Continue with **Knot the Door** and **Knock Once SSH Twice** to understand port-knocking concepts.
3. Practice **Knock Knock SSH Unlocked** for SSH-related access workflows.
4. Study **Knock Unlock Credentials** and **Knock and Crack SSH** for authentication-focused challenges.
5. Continue with **Knock Crack Escalate** and **Knock Crack Escalate 2** for escalation-oriented exercises.
6. Explore **Steghide Knockout** and **Base64 Breakpoint** to strengthen common CTF data-analysis skills.
7. Finish with **LXD Knocks: From Web Clue to Root** for a broader web-to-Linux privilege-escalation challenge.

## How to Use the Labs

- Read the instructions for each lab before starting.
- Use all techniques only inside the authorized CTF or training environment.
- Record discovered services, ports, credentials-related clues, and security observations.
- For port-knocking exercises, understand the purpose of the sequence and the network behavior involved.
- For SSH challenges, document the authentication concepts being demonstrated.
- For LXD challenges, study the Linux security and privilege concepts involved.
- For Steghide and Base64 challenges, verify decoded or extracted information carefully.
- Never apply these techniques against systems without explicit authorization.
